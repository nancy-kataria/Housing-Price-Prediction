# 🏡 Housing Price Prediction

This project demonstrates how to predict housing prices using Linear Regression. Built with Python in a Google Colab notebook, the project covers data exploration, visualization, and building a regression model to predict housing prices based on various features.

## Procedure
- Data Loading
- Exploratory Data Analysis (EDA)
- Data Preprocessing
- Model Building & Training
- Model Evaluation
- Visualization


## 🛠️ Tech Stack
- Python
- Google Colab Notebook
- **Pandas** for data handling
- **Seaborn** and **Matplotlib** for visualization
- **Scikit-learn** for machine learning

## 🎯 Learning Outcomes
- Practiced EDA techniques to understand the dataset
- Learned how to handle missing or irrelevant data
- Applied Linear Regression in Python
- Evaluated model performance using appropriate metrics
- Visualized data to derive meaningful insights
